# Release Notes v3.4.0

This release regenerates the `oag7/aha` client from an updated OpenAPI spec
(OpenAPI Generator 7.24.0), **greatly expanding the API surface** and **fixing
`aha ideas list`** ([#548](https://github.com/grokify/go-aha/issues/548)).

> **Note on versioning.** This is a **minor** release (v3.x) even though it
> contains breaking changes to `oag7/aha`. We are intentionally staying on `v3`
> to avoid forcing an import-path change (`/v3` → `/v4`) on every consumer. The
> breaking changes are limited to renamed methods and value→pointer field types;
> see [Migration](#migration) below.

## Highlights

- **Expanded API surface** — the regenerated client adds **Comments, Epics,
  Goals, Initiatives, Requirements, Strategic Models, Workflows, Custom Field
  Definitions, and Users**, plus Create/Update/Delete operations across entities.
- **Fixes `aha ideas list`** — the command previously failed for every domain
  with `no value given for required property votes`. `Idea.votes` is now optional.

## Fix: `aha ideas list` (#548)

`aha ideas list` failed with:

```
Error: failed to list ideas: no value given for required property votes
```

Root cause: the SDK marked `votes` as a **required** field, but Aha's list
endpoint **omits `votes` by default** (it's only returned when requested via the
`fields` parameter). The generated unmarshaler then rejected every list response.
`Idea.votes` is now an optional `*int32`, so listing ideas works regardless of
whether the field is present.

## Migration

The breaking changes are mechanical. If you use `oag7/aha` directly:

### 1. Collection methods renamed (`Get*` → `List*`)

| Before | After |
|--------|-------|
| `FeaturesAPI.GetFeatures(ctx)` | `FeaturesAPI.ListFeatures(ctx)` |
| `ProductsAPI.GetProducts(ctx)` | `ProductsAPI.ListProducts(ctx)` |
| `ReleasesAPI.GetProductReleases(ctx, productID)` | `ReleasesAPI.ListProductReleases(ctx, productID)` |
| `ReleasesAPI.UpdateProductRelease(...)` | `ReleasesAPI.UpdateRelease(ctx, releaseID)` |

Single-object getters (`GetFeature`, `GetProduct`, `GetRelease`, `GetIdea`) are
unchanged.

### 2. Optional and nullable fields are now pointers

Optional schema fields are now `*string` (etc.), and nullable fields are
`NullableString`. Use the generated safe accessors instead of the raw field:

```go
// Before:
name := cat.Name                 // string
date := *feature.Release.ReleaseDate

// After:
name := cat.GetName()            // returns "" if unset
date := feature.Release.GetReleaseDate()
```

Every optional field `X` has a `GetX() T` accessor that returns the zero value
when the pointer is nil, and nullable fields expose `Get() *T` / `IsSet() bool`.

## Upgrade

```bash
go get github.com/grokify/go-aha/v3@v3.4.0
```

The import path is unchanged (`github.com/grokify/go-aha/v3/...`).

See the [CHANGELOG](https://github.com/grokify/go-aha/blob/main/CHANGELOG.md) for
the full list of changes.
