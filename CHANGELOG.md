## [v3.4.0] - 2026-08-24

### Highlights

- Regenerated `oag7/aha` client (OpenAPI Generator 7.24.0), greatly expanding the API surface: Comments, Epics, Goals, Initiatives, Requirements, Strategic Models, Workflows, Custom Field Definitions, and Users, plus Create/Update/Delete across entities
- Fixes `aha ideas list` failing with "no value given for required property votes": the Idea `votes` field is now optional, matching Aha's list endpoint which omits it by default ([#548](https://github.com/grokify/go-aha/issues/548))

### Added

- `oag7/aha`: Comments, Epics, Goals, Initiatives, Requirements, Strategic Models, Workflows, Custom Fields, and Users API services, with Create/Update/Delete operations across entities ([`d4661e1`](https://github.com/grokify/go-aha/commit/d4661e1))

### Changed

- **BREAKING:** Collection operations renamed: `GetFeatures`/`GetProducts`/`GetProductReleases` -> `ListFeatures`/`ListProducts`/`ListProductReleases`; `UpdateProductRelease` -> `UpdateRelease` ([`d4661e1`](https://github.com/grokify/go-aha/commit/d4661e1))
- **BREAKING:** Optional and nullable fields are now pointers (`*string`) or `NullableString` instead of value types; use the generated `GetX()` accessors ([`d4661e1`](https://github.com/grokify/go-aha/commit/d4661e1))

### Removed

- `oag7/examples` programs (features_get, idea_feature_release), which duplicated the SDK quick start ([`ca047c2`](https://github.com/grokify/go-aha/commit/ca047c2))

### Fixed

- `aha ideas list` no longer errors when the API response omits `votes`; `Idea.votes` is now an optional pointer ([#548](https://github.com/grokify/go-aha/issues/548), [`d4661e1`](https://github.com/grokify/go-aha/commit/d4661e1))

### Dependencies

- _6 dependency updates_

- Refreshed README Supported APIs table for the expanded client ([`ca047c2`](https://github.com/grokify/go-aha/commit/ca047c2))

### Build

## [v3.3.0] - 2026-02-02

### Highlights

- New Cobra CLI for interacting with Aha! API from the command line
- Comprehensive idea-feature-release reporting with multiple output formats

### Added

- CLI: Cobra CLI with commands for ideas, features, products, releases, and reports ([`28c5f26`](https://github.com/grokify/go-aha/commit/28c5f26))
- CLI: `--inflate` flag to fetch full idea details including categories ([`30083d1`](https://github.com/grokify/go-aha/commit/30083d1))
- CLI: `--sort` flag for votes/created/updated ordering ([`30083d1`](https://github.com/grokify/go-aha/commit/30083d1))
- CLI: `--fail-on-error` flag for strict feature fetch error handling ([`30083d1`](https://github.com/grokify/go-aha/commit/30083d1))
- CLI: Progress bar during idea inflation ([`30083d1`](https://github.com/grokify/go-aha/commit/30083d1))
- SDK: `IdeaFeatureReport` and `IdeaFeatureReportSet` for comprehensive idea-feature-release reporting ([`e33b815`](https://github.com/grokify/go-aha/commit/e33b815))
- SDK: `GetIdeaFeatureReports()` with automatic pagination via `FetchAll` option ([`e33b815`](https://github.com/grokify/go-aha/commit/e33b815))
- SDK: `ListIdeas()` and `ListIdeasExecute()` in `IdeasAPIService` ([`cbd3b00`](https://github.com/grokify/go-aha/commit/cbd3b00))

### Fixed

- `CustomField.Value` now supports any type (string, array, etc.) matching actual Aha! API responses ([`f895ca6`](https://github.com/grokify/go-aha/commit/f895ca6))
- `Idea` model fields (`categories`, `votes`, timestamps) are now optional to handle varying API responses ([`961b1ca`](https://github.com/grokify/go-aha/commit/961b1ca))

- _3 dependency updates_

### Documentation

- README updated with quick start, API reference table, and corrected examples ([`7ae412a`](https://github.com/grokify/go-aha/commit/7ae412a))
